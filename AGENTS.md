# Reglas de Java Mastery Notes

- Editar los Markdown y MDX fuente en docs/, ejercicios/ y web-content/. No editar src/content/docs/: se regenera.
- Conservar los programas Java, verificadores y recursos visuales existentes.
- Prioridad pedagógica: transcripciones disponibles > apuntes derivados > libro de Joyce Farrell como refuerzo identificado > otras ampliaciones solicitadas.
- Distinguir clase, reconstrucción, ejercicio propio, código facilitado y ampliación. Nunca atribuir contenido no verificado al profesor.
- No publicar transcripciones privadas, conversaciones personales ni copias de libros.
- Crear páginas pequeñas y enlazadas; identificadores ASCII estables; un H1 por archivo; encabezados jerárquicos, tablas y bloques Java.
- Para una clase nueva: crear web-content/clases/apuntes/dia-NN.md y web-content/clases/dia-NN.md, actualizar el índice cronológico, registrar procedencia y alcance, enlazar temas existentes y comprobar las rutas.
- Para practicar: enunciado, razonamiento, pistas, casos de prueba, solución separada. Priorizar la colocación de instrucciones antes/dentro/después de los bucles.
- Antes de integrar: npm install, npm test, npm run build, npm run check:links y npm run test:web (Chromium instalado); verificar búsqueda, navegación, enlaces y ejemplos Java. No publicar ni fusionar sin aprobación.
