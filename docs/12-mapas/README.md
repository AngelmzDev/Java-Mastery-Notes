# Mapas: Hashtable y HashMap

> Ampliación didáctica propia a partir de los apuntes aportados por el propietario. Redacción, ejemplos y actividades nuevos; no se atribuyen a una clase concreta.

Un mapa guarda asociaciones entre claves y valores. Este bloque continúa el trabajo con arrays y bucles, y presenta colecciones que permiten añadir y eliminar entradas.

## Ruta de estudio

1. [Entender claves, valores y tablas hash](claves-valores-y-hash.md).
2. [Crear y utilizar Hashtable](hashtable.md).
3. [Trabajar con HashMap y elegir una implementación](hashmap.md).
4. [Resolver tres ejercicios](ejercicios.md).
5. [Contrastar las soluciones razonadas](soluciones.md).

Antes de empezar, repasa [arrays](../10-arrays/README.md), [comparación de cadenas](../05-strings/comparar-buscar-y-transformar.md) y [bucles](../07-bucles/README.md).

Los programas utilizan JDK 23 sin funciones preview. Los ejemplos de cada página son independientes. Cuando un bloque no declara una clase, es un fragmento para colocar dentro de `main`; sus imports se colocan al principio del archivo.
