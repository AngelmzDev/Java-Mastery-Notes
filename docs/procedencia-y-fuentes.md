# Procedencia, alcance y fuentes

## Qué se ha utilizado

La organización parte del encargo aportado por el propietario: contenidos básicos de Programación de DAM, clases 2 a 8, hasta introducción a arrays unidimensionales. Se inspeccionaron el README y las galerías anteriores del repositorio y se conservaron sus PDF e imágenes.

No estaban disponibles en el repositorio ni entre los adjuntos consultados estos archivos:

- `programacion_dia2_apuntes.md`
- `PRG_2026_Dia03_APUNTES.md`
- `PROG_DIA_4.md`
- `PROG_DIA_5.md`
- `PROG_DIA_6.md`
- `PROG_DIA_7.md`
- `PROG_DIA_8_APUNTES.md`

Por ello no se reconstruye una clase 1 ni se atribuyen las nuevas explicaciones al profesor. Si se incorporan esas notas, habrá que contrastar contenidos y estado de cada ejercicio; las ampliaciones didácticas de días 4 y 8 deberán distinguirse del contenido atribuido a clase.

## Etiquetas de los ejercicios

Todos los nuevos programas y explicaciones son **didácticos propios**. Las 24 aplicaciones están resueltas aquí; las 33 actividades son propuestas de práctica con respuesta separada. El estado **corregido / planteado / pendiente en clase es no confirmado**, incluso cuando una solución propia compila y pasa sus pruebas.

Los contextos, datos y redacciones se han variado conservando objetivos del encargo, no copiando unos enunciados originales que no estaban disponibles. Un ejemplo de ampliación propia es la regla gregoriana completa de bisiestos; no se afirma que su desarrollo corresponda a una clase concreta.

## Referencias técnicas oficiales

Las explicaciones se redactan de forma propia. Las referencias permiten contrastar sintaxis y comportamiento:

- [Fundamentos del lenguaje en Dev.java](https://dev.java/learn/language/constructs/basics/): variables, operaciones y control de flujo.
- [Scanner, API Java 23](https://docs.oracle.com/en/java/javase/23/docs/api/java.base/java/util/Scanner.html): tokens, líneas, configuración regional y errores de lectura.
- [String, API Java 23](https://docs.oracle.com/en/java/javase/23/docs/api/java.base/java/lang/String.html): comparación, índices, inmutabilidad y métodos de cadenas.
- [Math, API Java 23](https://docs.oracle.com/en/java/javase/23/docs/api/java.base/java/lang/Math.html): constantes, potencias y generación aleatoria.
- [Cambios del lenguaje en Java 23](https://docs.oracle.com/en/java/javase/23/language/java-language-changes-release.html): separación entre funciones estables y preview.
- [Crear un proyecto en IntelliJ IDEA](https://www.jetbrains.com/help/idea/creating-and-running-your-first-java-application.html): configuración del IDE. La guía actual usa versiones más nuevas; estos apuntes eligen explícitamente JDK 23, clase normal y main clásico.
- [Tutorial oficial de Git](https://git-scm.com/docs/gittutorial): repositorio, preparación, commits y remoto.

La documentación de API incluye muchas funciones fuera de nuestro alcance. No es necesario estudiarlas todas. No se introducen colecciones ni programación orientada a objetos avanzada por aparecer en una referencia.
