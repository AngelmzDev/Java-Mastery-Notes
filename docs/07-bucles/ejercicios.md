# Práctica: Bucles

Variantes didácticas propias: cambian los contextos y datos, conservando los objetivos de este bloque. El estado de corrección en clase no está confirmado.

**Cómo trabajar:** predice el resultado, escribe los pasos, resuelve, prueba los límites y explica una decisión del código. En las tareas de entorno o Git, documenta las acciones y lo que observas.

## 1. Serie de mantenimiento

**Objetivo:** Contar vueltas y controlar límites.

Muestra 6,9,12,15,18,21 con un for y luego la serie inversa con otro. Antes de ejecutar, escribe inicialización, condición y actualización de cada uno. No imprimas el 24 ni el 3.

**Comprueba:** Seis vueltas en cada bucle.

## 2. Clave de laboratorio

**Objetivo:** Repetir hasta una condición de parada.

Pide una clave hasta que coincida exactamente con JAVA o se termine la entrada. Cuenta todas las propuestas recibidas, incluida la acertada. Usa un único Scanner, equals para comparar y explica si while o do while permite representar mejor la primera lectura.

**Comprueba:** Con java, DAM, JAVA se aceptará en 3 intentos; un EOF inicial produce cero propuestas.

<details>
<summary>Pista</summary>

El requisito de EOF inicial puede hacer preferible while con hasNextLine.

</details>

## 3. Triángulo y salto

**Objetivo:** Combinar bucles anidados y filtros.

Dibuja un triángulo de cuatro filas, con una estrella en la primera y cuatro en la última. Después recorre 1..12 y muestra solo los que no sean múltiplos de 4. Resuelve el filtro con if y luego con continue; compara el razonamiento.

**Comprueba:** Filas con 1,2,3,4 estrellas; números 1,2,3,5,6,7,9,10,11.

<summary>Pista</summary>

El println de la figura va después del bucle de columnas.

</details>
